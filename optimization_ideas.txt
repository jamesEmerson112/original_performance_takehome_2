THEORETICAL LIMITS
================================================================================

VALU-bound (all ops):
  32 chunks x (1 XOR + 18 hash + 3 index + ~1 selection) x 16 rounds
  = 32 x 23 x 16 = 11,776 ops / 6 = 1,963 cycles minimum

LOAD-bound (direct rounds):
  32 chunks x 8 loads x 12 direct rounds / 2 LOAD slots = 1,536 cycles

Target <1,600 is BELOW theoretical VALU minimum!
This suggests either:
  1. Target is unachievable with current algorithm
  2. There's a fundamentally different approach needed
